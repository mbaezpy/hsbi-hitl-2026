# Annotation design review examples

Open `task-a-research-screening.html` or `task-b-receipt-extraction.html` directly in a modern browser. Each file works independently, offline, without a server or installation.

Use the guidelines beside the item, complete the annotation, and select **Submit annotation** to review the locally recorded response. Edit and resubmit, or use **Reset** to start again. Responses are kept only in the current page and are lost when it is reloaded; nothing is sent to a server.

Select **Reveal Design Issues** to display the instructor review and highlight the related elements; select it again to hide the review. **Print student** prints the complete task without the review. **Print instructor** includes the review. In the browser print dialog, choose a printer or **Save as PDF**. The task may span several A4 pages.

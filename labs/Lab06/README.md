# Lab 06 — Designing and piloting annotation tasks

This lab brings together task specifications for designing annotation tasks, Label Studio setup guides and labeling-interface templates, and notebooks for preparing and analyzing annotation data.

Start with the [Label Studio quickstart](label_studio_setup/quickstart_project.md) to set up a project. The [task specifications](task_specification/) provide examples of how to describe an annotation task, and [label_studio_setup](label_studio_setup/) contains configuration guidance and interface templates.

## Materials

- [01_prepare_banking.ipynb](01_prepare_banking.ipynb) — prepare BANKING77 text-classification tasks.
- [01_prepare_realwaste.ipynb](01_prepare_realwaste.ipynb) — prepare RealWaste image-classification tasks.
- [01_prepare_cord.ipynb](01_prepare_cord.ipynb) — prepare CORD information-extraction tasks using OCR.
- [02_analyze_classification.ipynb](02_analyze_classification.ipynb) — analyze a classification pilot.
- [02_analyze_ie.ipynb](02_analyze_ie.ipynb) — analyze an information-extraction pilot.
- [task_specification/](task_specification/) — example task specifications.
- [label_studio_setup/](label_studio_setup/) — setup guides and labeling-interface templates.
- [utils/](utils/) — helpers used by the notebooks.

The preparation notebooks illustrate different annotation scenarios. Use the analysis notebook that fits your task and adapt it to your own project.
